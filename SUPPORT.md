# Support

For template topology, the owner bootstrap, service wiring and Railway deployment issues, open an issue in this repository. For survey, response and application behavior, use the [Formbricks project](https://github.com/formbricks/formbricks) and its [documentation](https://formbricks.com/docs). For Hub, see [Formbricks Hub](https://hub.formbricks.com); for authorization internals, [SpiceDB](https://github.com/authzed/spicedb); for the analytics layer, [Cube](https://github.com/cube-js/cube).
